# Security policy

This is experimental software and is not a hardened sandbox for untrusted executables. Run only content you are authorized to use and avoid running as an administrator.

Do not disclose vulnerabilities by posting unredacted crash reports, game dumps, tokens, or personal paths in public issues. When a GitHub repository is established, use its private security-reporting feature if enabled.

For public issues, prefer a minimal source-level reproduction with synthetic input and no personally identifying metadata.
