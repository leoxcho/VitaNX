# Public-source release notes

This archive omits all precompiled ELF and binary fixtures pending independent provenance verification. Some tests requiring those fixture binaries cannot run until the user regenerates them from the provided sources with their own authorized toolchain. No commercial game files, firmware or saves are included.

Before publishing: verify third-party notices and dependency licenses, GitHub private email and identity, final staged diff, and authorization for the destination repository. No Git history is bundled.
